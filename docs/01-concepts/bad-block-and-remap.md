# 坏块扫描与地址重映射

坏块管理通过介质扫描、坏块表和替换空间，将不可用物理位置排除出正常数据路径。扫描参数与地址编码依赖具体 NAND（NOT AND，非与型闪存） 和控制器。

## 1. 坏块来源

| 类型 | 来源与识别方式 |
| --- | --- |
| 出厂坏块 | 制造测试发现，通常在指定页或 OOB（Out-of-Band，页备用区） 位置记录标记 |
| 增长坏块 | 在后续擦写、老化或运行中发现，由测试结果和固件状态记录 |

扫描需要覆盖所选 NAND 配置规定的标记页、偏移和寻址范围。仅能读写部分页面，不能证明所有块或所有接口模式均正常。

## 2. 原始扫描与擦除扫描

原始坏块扫描读取规定位置的标记或状态；擦除扫描执行所选擦除与检查流程，记录擦除失败及相关异常。两者产生的信息需要按同一地址口径合并。

在 SM2263XT 示例协议中：

| 阶段 | 提交与结果命令 |
| --- | --- |
| Org 扫描 | C1/91 提交，C2/85 取结果 |
| ScanErase | C1/92 提交，C2/83 取结果 |

扫描描述符由 profile 派生，包含 T、R、mode、pages 和 offsets。批次数、扫描时长和擦除范围随配置变化。

### SM2263XT 示例记录

本次项目的一组测试使用 `T=495, R=64, mode=1`：Org 重复扫描三次，16 个块稳定被判坏；按并集合并后记录为 18 行、66 bit，包含两个结果不稳定的块。另一轮擦除扫描完成 8 批，未发现新增坏块。这些数字对应具体测试记录，不是该型号的固定结果。

重复扫描可能发现边缘块的状态波动。并集保留任一次扫描发现的坏块，交集仅保留各次均发现的坏块。工具通过 `bbt build --policy` 选择合并策略；合并时应保留扫描来源和统计口径。

## 3. 坏块表

坏块表（BBT（Bad Block Table，坏块表））记录不可用物理位置。其编码可以是逐块标记、位图或其他压缩结构，大小由几何与实现决定。

SM2263XT 工具的示例输出包括：

| 文件 | 内容 |
| --- | --- |
| bbt.bin | 坏块映射缓冲，262,144 B |
| bbt-compact.bin | 压缩表示，此格式为 528 B |
| counters.bin | 扫描合并统计 |

坏块行数还写入 P+0x3E。行数、置位数和物理坏块数量属于不同统计口径，对照时需要先确认定义。

## 4. 替换地址与 DiffAddr

固件需要将不可用地址排除或替换。替换位置从预留空间分配，并与容量、系统区和地址组织保持一致。

SM2263XT 的 DiffAddr 按行和槽组织地址关系。生成过程包括建立 `(block, plane, channel, CE)` 矩阵、筛选坏块、分配替换地址及检查映射，最终输出 64 KiB 表和更新后的参数。

```sh
ossd diffaddr build --param P --drive D --bbt bbt.bin \
                    --compact bbt-compact.bin --out DIR
```

该命令属于本项目的 SM2263XT 实现，不能直接用于其他主控的映射格式。

## 5. 坏块与容量分配

可分配容量取决于好块数量、系统区、SLC（Single-Level Cell，每单元存储 1 bit） 配置、替换空间及目标容量。坏块增加可能消耗预留空间，也可能使目标容量无法满足；主机报告容量不一定随每个坏块变化。

SM2263XT 示例采用以下分配口径：

```text
总块数                  495
减去坏块行               18
减去系统区占用单位        1
减去静态 SLC 区          37
剩余数据候选单位        439
按预留策略保留           41
用户数据 FBlock         398
```

这里的系统区占用单位与四个系统物理位置不是同一计数口径。公式中的单位需要按控制器几何解释，不能混用。

## 6. 结果对照与使用条件

不同扫描轮次、测试策略或固件版本可能产生不同坏块表，继而改变 DiffAddr 和系统镜像长度。逐字节差异需要回溯到扫描输入及转换规则，不能直接认定为故障或无害差异。

本次项目曾观察到 Python 路径与原厂路径的 Org 数据前 31,680 B 一致，而后续擦除统计和最终坏块行数不同。该记录用于说明分阶段对照的必要性；不能由一次成功启动推断另一组坏块数据的长期可靠性。

有效的坏块信息是容量分配和替换映射的输入。若复用已有结果，需要确认其介质、配置和地址口径一致；若可用空间不足，则无法按原目标容量完成分配。
