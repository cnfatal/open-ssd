# YMTC X2-9060（`9B C5 29 49 20 00`）

本文记录项目示例设备选用的 NAND 配置：8Tbit、16 die、TLC（Triple-Level Cell，每单元存储 3 bit）。

## 1. 标识

```text
Flash ID    9B C5 29 49 20 00
型号        YMN09TC1B1OC6C(TAS)(2Die)(SM2263XT)
Flash.SET   A2（别名）
类型        TLC，128 层
```

## 2. 几何

```text
通道        4（CH0..CH3）
CE          8（每通道 CE0、CE2）
die/CE      2
总 die      16
页          16 KiB（32 个 512 B 扇区）
页/块       2304
块/die      1980（4 个 plane × 每 plane 495）
扫描用 T    495（每 plane 块数）
数据 FBlock 398
扇区/FBlock 4,712,448
用户容量    960,197,124,096 B
```

## 3. 型号识别与拓扑确认

```sh
sudo ossd read flash-id        # 期望 9B C5 29 49 20 00
sudo ossd pretest connectivity --drive D.bin --out DIR --allow-probe
```

连通性矩阵应为：

```text
ch\ce   0     1     2     3
 0     0x03  0x00  0x03  0x00
 1     0x03  0x00  0x03  0x00
 2     0x03  0x00  0x03  0x00
 3     0x03  0x00  0x03  0x00
```

8 个非零格 × 2 die = 16 die，对应 8Tbit / CE（Chip Enable，片选）=8。

## 4. Flash.SET 行

```text
YMTC,8Tbit,YMN09TC1B1OC6C(TAS)(2Die)(SM2263XT)=
9B,C5,29,49,20,00, 4,16,2048,036864,2304,01980,00000,00800,
04,02,08,2,D1,00,0,99,7F,13,0303,DA,DF,...
```

关键列：

```text
前 6 列    颗粒 ID
第 7 列    通道数 4
第 8 列    位宽 16
第 9 列    页大小 2048（单位见工具解析：16 KiB）
第 17 列   die/CE = 2
第 19 列   CE = 8
```

工具解析结果应为：

```text
geometry: page=16 spare=2048 block=1980 pages/block=2304 plane=4 ce=8 ch=2
```

## 5. Flash.SET 配置行选择

配置行由 `ossd select` 根据配置文件和设备信息选择：

```text
System.ini [INITIAL] IniName      → YMTC_TAS_ISP_2DIE
Config/<ini> FlashPartNum         → 原厂默认 2Tbit，与此示例不匹配
C2/40 颗粒 ID                     → 9b c5 29 49 20 00
C2/80 拓扑                        → 8 CE × 2 die
Flash.SET 精确匹配                → YMTC,8Tbit,YMN09TC1B1OC6C
```

原厂 ini 指向的 `2Tbit HC6C` 是 `9B C4 28`、CE=4，与项目示例设备不符；工具会报错并列出
同 ID 的两个候选，确认后用 `--allow-part A2` 显式选择。

## 7. 常见错误

| 现象 | 原因 |
| --- | --- |
| `FlashConnectivity` 失败 | 选了 A1（4 CE）或 A0（2Tbit） |
| 只认出 4 个 CE | 矩阵实际是 8 格，参数却按 4 格算 |
| 容量只有一半 | 用了 4Tbit 行（8 die 而非 16 die） |
| 扫描批数不对 | R 或 T 与几何不匹配 |

## 8. 同 ID 的其他配置

`9B C5 29 49 20 00` 也出现在 A1（`YMN09TC1B1JC6C`，4Tbit）：

```text
A1  4 CE × 2 die = 8 die  → 512 GB 档
A2  8 CE × 2 die = 16 die → 1 TB 档（项目示例设备）
```

区别只在 CE 数，必须靠 `C2/80` 的矩阵区分，不能仅凭 ID 区分。
